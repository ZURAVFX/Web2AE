# Web2AE v1.0.0

First public release of Web2AE: live web → editable After Effects layers.

### Highlights
- Chrome / Edge high-fidelity render-tree capture
- Firefox live-DOM capture
- editable text + native shape reconstruction
- element-level raster fallback for complex CSS/media
- semantic precomp grouping with paint-order safety
- local-only browser → After Effects bridge
- no API keys, subscriptions or cloud processing

### Install
1. Download **Web2AE_v1.0.0_Companion_Windows.zip** and run `Install Web2AE.bat`.
2. Install the Web2AE browser extension from Chrome Web Store or Firefox Add-ons (or load the development build).
3. Open **Window → Extensions → Web2AE** in After Effects.
4. Open a webpage and click **Send Current Page to AE**.

See `docs/USER_GUIDE.md` for details.
